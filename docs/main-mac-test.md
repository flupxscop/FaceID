# ทดสอบบนเครื่องหลัก (ต้องใช้กล้องจริง)

ข้อที่ทำใน VM ไม่ได้ เพราะ VM macOS บน Apple silicon ไม่มีกล้อง ผลใน VM อยู่ที่ [plugin-vm-test.md](plugin-vm-test.md)

แบ่งเป็น 2 ช่วง: **ช่วง A ไม่ติดตั้ง plugin** (ปลอดภัย ไม่แตะ authorizationdb) และ **ช่วง B ติดตั้ง plugin**
(ทำหลังช่วง A ผ่าน และเตรียมทางกู้คืนแล้วเท่านั้น)

## เตรียม

Build release (ไม่ต้องใช้ sudo):

```bash
Scripts/build-app.sh
```

อัปเดตตัวที่ติดตั้งไว้ (ยังไม่มี plugin):

```bash
sudo Scripts/install.sh
```

ถ้าแอปขึ้นปุ่ม "อนุญาต" ให้กด แล้วเลือก Always Allow (ไม่ต้องลงทะเบียนใหม่) — เป็นการทดสอบปุ่มนี้ไปด้วย (K1)

เปิดหน้าต่าง log ค้างไว้:

```bash
log stream --predicate 'subsystem == "com.example.faceid"' --level info
```

## ช่วง A: ไม่มี plugin (สแกนจากแอป Menu Bar › "ทดสอบสแกนใบหน้า")

| # | ทำอะไร | ผลที่ต้องได้ | ผลจริง |
|---|---|---|---|
| K1 | อัปเดตแล้วเปิดแอป | ถ้ามีปุ่ม "อนุญาต" กดแล้วสแกนได้โดยไม่ต้องลงทะเบียนใหม่ | |
| A0 | สแกนด้วยหน้าตัวเอง (กะพริบตา หันซ้าย–ขวา) | ✅ จำใบหน้าได้ | |
| S1 | ถือ**รูปพิมพ์บนกระดาษ**ของตัวเองหน้ากล้อง ลองทั้งนิ่งและขยับ/หมุนรูป | ไม่ผ่านทุกครั้ง | |
| S3 | เปิด**วิดีโอของตัวเอง**ที่กะพริบตาและหันซ้าย–ขวา บนจอมือถือ/แท็บเล็ต | ไม่ผ่าน (ส่วนใหญ่ควรไม่ผ่านเพราะทิศถูกสุ่ม) ลองอย่างน้อย 5 ครั้ง บันทึกจำนวนที่ผ่าน | |
| F3a | สแกนให้ไม่ผ่าน 3 ครั้งติดกัน (เช่น ใช้รูปบนมือถือ) | ครั้งที่ 3 แล้วแอปขึ้น "พลาดหลายครั้ง ปลดล็อกด้วยรหัสผ่านหนึ่งครั้ง…"; สแกนครั้งที่ 4 ด้วยหน้าจริงก็ไม่ผ่าน | |
| F3b | ล็อกหน้าจอ (⌃⌘Q) แล้วปลดล็อกด้วยรหัสผ่าน จากนั้นสแกนหน้าจริง | ข้อความล็อกหาย และ ✅ จำใบหน้าได้ | |
| F1a | เริ่มสแกนแล้วหันหนีกล้อง | ภายใน ~5 วินาที ขึ้น "หมดเวลา" และไฟกล้องดับ | |

> S3: ถ้าวิดีโอผ่านได้บ่อย ให้บันทึกไว้ — เป็นข้อมูลสำหรับตัดสินใจเรื่อง liveness (CLAUDE.md §6) ห้ามแก้ค่าเองโดยไม่ถาม

## ช่วง B: ติดตั้ง plugin (หลังช่วง A ผ่าน)

ก่อนติดตั้ง **ต้อง**:

- [ ] เปิด Remote Login (SSH): การตั้งค่าระบบ › ทั่วไป › การแชร์ › การเข้าสู่ระบบระยะไกล
- [ ] ลอง `ssh` เข้าเครื่องนี้จากเครื่องอื่น (หรือโทรศัพท์) ให้ได้จริง
- [ ] เก็บ [Scripts/recovery.md](../Scripts/recovery.md) ไว้ในเครื่องอื่น/โทรศัพท์

```bash
sudo Scripts/install.sh --with-plugin --allow-host
```

| # | ทำอะไร | ผลที่ต้องได้ | ผลจริง |
|---|---|---|---|
| E6 | ล็อก (⌃⌘Q) → ปลุกจอ → **กด Return** → มองกล้อง กะพริบตา หันซ้าย–ขวา | ปลดล็อกโดยไม่ต้องพิมพ์รหัสผ่าน | |
| E6c | ล็อก → Return → หันหนีกล้อง | ช่องรหัสผ่านขึ้น และรหัสผ่านปลดล็อกได้ | |
| F4 | ล็อก → Return → ระหว่างสแกน เริ่มพิมพ์รหัสผ่านแล้วกด Return | ไฟกล้องดับ และรหัสผ่านใช้ได้ | |
| F3c | ล็อก → ให้สแกนไม่ผ่าน 3 ครั้ง → ครั้งที่ 4 | ครั้งที่ 4 ไปช่องรหัสผ่านทันทีโดยไม่เปิดกล้อง | |
| W | (ไม่ต้องทำ) watchdog ทดสอบใน VM แล้ว — **ห้ามลอง** ลบ plugin บนเครื่องหลัก | | |

ถ้ามีอะไรผิดปกติ: SSH เข้ามาแล้วรัน

```bash
sudo "/Library/Application Support/FaceID/uninstall.sh" --restore-authdb-only
```

## R6: หลังถอนการติดตั้ง (ทำเมื่อเลิกทดสอบแล้วเท่านั้น — จะลบข้อมูลใบหน้า)

```bash
sudo "/Library/Application Support/FaceID/uninstall.sh"
```

ต้องไม่เจอรายการใดเลย (ทุกบรรทัดต้องขึ้นว่าหาไม่พบ):

```bash
for a in template template-key.secure-enclave template-key.software; do security find-generic-password -s com.example.faceid -a $a >/dev/null 2>&1 && echo "STILL THERE: $a" || echo "absent: $a"; done
```
